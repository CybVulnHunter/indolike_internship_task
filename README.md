# 🚀 Internship Task Collection - Final Summary

Welcome to the **Indolike Internship Task Repository**, a collection of diverse and practical Python projects aimed at solving real-world problems. This repository features five essential tools, each designed to enhance productivity, automate tasks, and provide valuable utilities.

## 🔥 Projects Overview

2️⃣ **Scientific Calculator** - A feature-rich calculator using Tkinter, supporting basic arithmetic, trigonometric, and logarithmic functions with an intuitive GUI.

3️⃣ **Web Scraper & Link Extractor** - A Python-based tool that fetches and extracts links from webpages, categorizing them into different types for better analysis.

4️⃣ **Joke Generator** - A fun and interactive script that delivers random programming jokes using the `pyjokes` library, bringing humor to developers.

5️⃣ **To-Do Task Manager** - A command-line utility for managing daily tasks with options to add, view, mark as done, and save tasks persistently.
