# Scientific Calculator using Tkinter

## 🌟 Overview

This is a simple yet powerful scientific calculator built using Python's Tkinter library. It supports basic arithmetic operations as well as advanced mathematical functions such as trigonometry, logarithms, and exponential calculations. 🧑‍🔬

## 🚀 Features

- ➕➖✖️➗ **Basic arithmetic operations:** Addition, Subtraction, Multiplication, Division, and Modulus.
- 📐 **Scientific functions:** Square root, Logarithm (log, log2, log10), Exponential, and Factorial.
- 🎯 **Trigonometric functions:** sin, cos, tan, sinh, cosh, tanh.
- 🔢 **Constants:** Pi (π), Tau (τ), and Euler's number (e).
- 🔄 **Toggle sign function** (positive/negative).

## 📦 Requirements

- 🐍 Python 3.x
- 🖥️ Tkinter (included in standard Python distribution)
