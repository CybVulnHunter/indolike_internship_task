# ✅ ToTask - A Simple To-Do List 

## 📌 Overview
ToTask is a simple command-line to-do list manager written in Python. It allows users to add tasks, view them, mark them as done, and save their tasks for future use. 📝✨

## 🚀 Features
- ➕ **Add Tasks** - Quickly add new tasks to your list.
- 📋 **View Tasks** - Display all pending tasks.
- ✅ **Mark as Done** - Remove completed tasks from the list.
- 💾 **Persistent Storage** - Saves tasks to a file so they are available even after restarting.

## 📦 Requirements
- 🐍 Python 3.x

## ⚙️ Installation
Clone the repository using the following command:
```sh
🚀 git clone https://github.com/CybVulnHunter/indolike_internship_task.git
📂 cd indolike_internship_task
```

## ▶️ Usage
Run the script using Python:
```sh
🖥️ python to_do_task.py
```
Follow the menu options to add, view, and manage your tasks. 📌

## 💡 How It Works
1️⃣ Run the script.
2️⃣ Choose an option from the menu:
   - `1` to add a task.
   - `2` to view tasks.
   - `3` to mark a task as done.
   - `4` to exit.
