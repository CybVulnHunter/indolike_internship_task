# 😂 Joke Generator

A fun Python script to generate programming jokes using the `pyjokes` library. 🎭

## 🔧 Features
- Generate a random programming joke.
- Generate multiple programming jokes at once.
- Supports different languages (default: English).
- Interactive command-line interface.

## 🛠️ Requirements
Ensure you have **Python 3.x** installed and install `pyjokes`:
```bash
pip install pyjokes
```

## 🚀 Usage
1. Clone the repository or download the script:
   ```bash
   git clone https://github.com/CybVulnHunter/indolike_internship_task.git
   cd indolike_internship_task
   ```
2. Run the script:
   ```bash
   python joke_generator.py
   ```
3. Choose an option:
   - Generate a random joke.
   - Generate multiple jokes.
   - Exit the program.

