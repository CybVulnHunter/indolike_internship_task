# 📦 File Compression Tool

A simple and efficient Python script to compress files or folders into `.zip` or `.tar.gz` formats. 🚀

## 🔧 Features
- Compress multiple files or folders into a **ZIP** archive.
- Compress multiple files or folders into a **TAR.GZ** archive.
- Automatically handles missing files with warnings.
- Simple user input for easy usage.

## 🛠️ Requirements
Ensure you have **Python 3.x** installed.

## 🚀 Usage
1. Clone the repository or download the script:
   ```bash
   git clone https://github.com/CybVulnHunter/indolike_internship_task.git
   cd indolike_internship_task
   ```
2. Run the script:
   ```bash
   python File_compression_Tool.py
   ```
3. Enter the file or folder paths (comma-separated) to compress.
4. Specify the output file name with **.zip** or **.tar.gz** extension.

## 📌 Example
```shell
Enter the file/folder paths to compress (comma-separated): example.txt, image.png, folder
Enter the output file name with extension (.zip or .tar.gz): archive.zip
Compressed files to archive.zip
```
